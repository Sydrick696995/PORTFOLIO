FEATURED PROJECT / CASE STUDY

CareerGraph

Graph Database Career Exploration Platform

A hosted web application that helps users explore career paths by connecting starting skills, target roles, required skills, projects, and learning resources through a graph database.

LIVE DEMO WATCH VIDEO BACK TO PROJECTS

01 / PROBLEM

Why a graph?

Career planning is naturally connected: one skill can support several roles, roles require multiple skills, projects can demonstrate those skills, and resources can teach them. A graph model represents those relationships directly instead of flattening them into unrelated lists.

02 / MODEL

03 / IMPLEMENTATION

What I built

Multi-hop reasoning

Cypher traversals connect multiple graph entities to produce career paths and recommendations.

Parameterized queries

Database operations use the official Neo4j driver with parameters instead of concatenated Cypher.

Reliable UX

Loading, empty, validation, and database-error states help users understand what the application is doing.

Interactive visualization

The visualization reflects nodes and relationships returned for the selected career exploration.
